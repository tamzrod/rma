## Implemented core hardening (previously unverified checkpoint, now executed)
- Registry protected by `sync.RWMutex`; per-bank `sync.RWMutex` gives atomic bounded single-bank read/write and independent read copies.
- Unknown banks return `ErrBankNotFound` instead of a nil-pointer panic.
- Bank sizing checks `UnitWidthBits`/`Units` and multiplication overflow before allocation; `bitsToBytes` divides before rounding up so it cannot overflow at `math.MaxUint64`.
- Logical-unit span bounds are checked before offset arithmetic, so `start * width` and `count * width` cannot overflow for any accepted request.
- `BuildFromSpecs` validates the whole batch (duplicates, per-bank size, aggregate capacity) before allocating or publishing any bank; `Seal` is serialized with layout building.
- Capacity contract retained: 64 MiB per bank, 256 MiB aggregate, rejected with `ErrMemoryTooLarge`.
